# Aperture OS – Splash screen

```text
◉ APERTURE LABORATORIES
  AUTOMATED TESTING FACILITY

INITIALIZING APERTURE OS ............ OK
LOADING TEST CHAMBER ................ OK
CALIBRATING PORTAL DEVICE ........... OK
VERIFYING TEST SUBJECT .............. OK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SYSTEM READY
WELCOME, TEST SUBJECT _
```

The lines are tied to Plasma's real startup phases (`stage` 1–6). The splash therefore never
artificially prolongs startup – it disappears as soon as the desktop is ready (typically 1–2 s).
Background: heavily darkened core maintenance hall (`images/background.jpg`). Animations: logo rotation, progress line, cursor blink
(off with `motion.reduceMotion`).

## Installation

```bash
./install.sh              # to ~/.local/share/plasma/look-and-feel/aperture-os.splash
./install.sh --activate   # set as the splash screen
./install.sh --preview    # preview (test mode)
./install.sh --uninstall
```

Or: System Settings → Colors & Themes → Splash Screen → *Aperture OS*.
The `aperture-os` Global Theme contains a copy of this splash.

## Customization

Texts: `lines` in `aperture-os.splash/contents/splash/Splash.qml`. Colors/fonts: `ApertureTokens.qml`,
generated by `tools/build.py` from `tokens.json`.
