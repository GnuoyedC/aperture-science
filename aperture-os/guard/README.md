# Aperture OS – Plasma update guard

The Aperture OS lock and logout screens are adapted copies of the Plasma 6.6 originals.
A Plasma update can make them incompatible. A broken lock screen is the worst case on a work machine
("The screen locker is broken" → unlocking only possible via TTY). This module prevents that.

| Check | On problem |
|---|---|
| The Aperture lock screen is loaded invisibly (`QT_QPA_PLATFORM=offscreen`, 6 s) | **disabled immediately** (the default lock screen takes over on the next lock) + critical notification |
| The Aperture logout screen is loaded invisibly | Notification |
| Plasma originals vs. `baseline.sha256` | one-time notification "please compare" – Aperture keeps running |

**When:** at every login (60 s after system start via `aperture-plasma-guard.timer`, decoupled from session start, low priority) and automatically as soon as a
package update changes the Plasma files (`aperture-plasma-guard.path`). No permanent process.

The `.path` unit is generated by `install.sh` from `systemd/aperture-plasma-guard.path.in`: systemd cannot use variables, and the
`kscreenlocker_greet` location differs per distro/arch (Debian/Ubuntu multiarch, Fedora `/usr/libexec`, Arch `/usr/lib`). The guard
resolves it at runtime (`aperture-plasma-guard --print-greeter`); re-run `install.sh` if the path ever changes.

## Installation

```bash
./install.sh               # installs to ~/.local/share/aperture-os/guard, enables the units
./install.sh --uninstall
aperture-plasma-guard --status   # check manually without changing anything
```

Logs: `~/.local/state/aperture-os/guard*.log`.

## After a "Plasma update: compare Aperture copies" notification

```bash
# 1. What did KDE change?
diff -u <(git show HEAD:lockscreen/aperture-os.shell/contents/lockscreen/LockScreenUi.qml) \
        /usr/share/plasma/shells/org.kde.plasma.desktop/contents/lockscreen/LockScreenUi.qml
# 2. Adopt the new originals and re-apply the sections marked "Aperture OS"
#    (lockscreen/: LockScreenUi.qml, globaltheme/: contents/logout/Logout.qml)
# 3. test
lockscreen/install.sh --preview
"$(dirname "$(guard/aperture-plasma-guard --print-greeter)")"/ksmserver-logout-greeter --windowed --lookandfeel aperture-os
# 4. record the new baseline and install
guard/aperture-plasma-guard --rebaseline && guard/install.sh
lockscreen/install.sh --activate --now   # if the guard had disabled it
```
