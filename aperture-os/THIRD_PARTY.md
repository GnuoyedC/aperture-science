### Kvantum theme (`kvantum/`)

`kvantum/ApertureOS/` is generated by `kvantum/tools/build.py` from **KvFlat** by Tsu Jan (Kvantum project,
GPL-3.0-or-later), recoloured to the Aperture tokens. The base theme is read from `/usr/share/Kvantum/KvFlat` at
build time and is not stored separately. The derived output is GPL-3.0-or-later.

### Kate / KSyntaxHighlighting theme (`kate/`)

`kate/aperture-os.theme` is generated by `kate/tools/build.py` (MIT per the theme metadata, (c) 2026 Quatzler).
The file structure and style names follow the theme format and the shipped KDE syntax-highlighting themes
(MIT-licensed, KDE Frameworks); the palette is the Aperture one.
