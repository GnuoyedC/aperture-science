# Aperture OS – Plasma Style

Plasma Style **Aperture OS**: tinted security glass instead of glassmorphism.

| Element | Look |
|---|---|
| Panel | dark, 88 % opaque + blur, 1-px border, lighter corner brackets, **orange accent line** on the edge facing the desktop (top for a bottom panel, etc.) |
| Popups, launcher, notifications, KRunner | 84 % opaque + blur, 1-px border with corner brackets, subtle shadow |
| Lists (launcher, tray popups) | Hover: fill + 2-px signal bar on the left in orange; selection: orange tone |
| Task bar | Indicator line at the screen edge: gray = running, blue = hover, **orange = active**, amber = attention |
| Desktop widgets | 80 % opaque, blue corner brackets |
| Tooltips | almost opaque (96 %) |

Only these SVGs are shipped; everything else (scrollbars, switches, sliders …) comes from Plasma's
default theme and automatically picks up the Aperture colors. Variants without transparency are in
`opaque/` (without compositing) and `solid/` (panel mode "opaque").

## Installation

```bash
./install.sh              # to ~/.local/share/plasma/desktoptheme/aperture-os
./install.sh --activate   # + activate
./install.sh --uninstall  # remove; if it was active, Breeze is set
```

Or: System Settings → Colors & Themes → Plasma Style → *Aperture OS*.

## Customization

Everything is generated by `tools/build.py` from `tokens.json` (transparency: `alpha.panel`, `alpha.glass`,
`alpha.widget`, `alpha.tooltip`; radii: `geometry`). `ApertureOS.colors` is copied in by the main repo from
`colors/`.

```bash
python3 tools/build.py && ./install.sh --activate
```

Note: Plasma caches SVGs. If changes do not show up, briefly select a different Plasma Style
and switch back.
